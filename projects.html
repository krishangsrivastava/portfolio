PROJECT 01 Status: Completed
Vehicle Dynamics & Tyre Engineering

Racing Tyre Characterisation & Performance Modelling

Investigated the force-generating characteristics of racing tyres using experimental tyre-test data in MATLAB. Analysed lateral force against slip angle across vertical load bands (200 N to 1100 N) and camber settings (0°, 2°, 4°) to evaluate cornering stiffness and tyre limits for vehicle dynamics modelling.

MATLAB Lap-Time Simulator

PROJECT 04 Status: Completed Prototype
Embedded Systems & Motorsport Data Acquisition

IMU-Based Vehicle Motion Data Acquisition System

Developed a prototype inertial-sensor data acquisition system using an ESP32 microcontroller and MPU6050 6-axis IMU over I²C (0x68). Built a Python serial-logging pipeline storing 1035 motion samples to CSV for longitudinal/lateral G-force and yaw velocity analysis during vehicle testing.

Key Verified Output / Deliverable:
Working I²C Sensor Comm (0x68), ESP32 Hardware Prototype & 1035 CSV Motion Samples
ESP32, Python, CSV
